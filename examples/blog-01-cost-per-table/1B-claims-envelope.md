## 2. THE ENVELOPE FOR THIS POST

`P = —` means the entire "comparison intent" of the brief must be served **without a single
performance number or comparison**. Excluded everywhere — title, meta, H1–H3, table headers,
bullet labels, captions, alt text, CTA button text:

| Excluded | Rule |
|---|---|
| any number/percentage about cleaning performance | no code P |
| lab-tested · lab-verified · independently tested · proven · clinically | locked to Tier 2 (Fitness + EMPOWER) |
| outperforms · better than · more effective · beats · X% more · X times | needs product+soil+surface+lab matching Annex A |
| safe · safe on · surface-safe · won't damage · guaranteed not to | "never 'safe' for a surface"; only **"safe on sensitive skin"** (S3, skin designation) |
| all / any / every surface, finish, floor | name the material, or "most" |
| hygienic clean · sanitary surfaces · kills what's on the table · protects guests | germ-kill by implication on a non-registered product |
| best · safest · most effective · strongest · #1 · ultimate | unsubstantiated superlatives |
| non-toxic · chemical-free · harmless · kid & pet safe | prohibited in all forms incl. metas |
| **food-safe · food-grade · food-contact approved** | prohibited regardless of context — **even for the NSF-certified SKU** |
| bare "compostable" | must use the full cloth-substrate sentence + disclaimer |
| **"Sustainable"** as a bare word | forbidden on both rows |
| "100% natural" / "X% natural" | code N allows "made with natural ingredients" only |
| any Tier 2 claim | results **never transfer** to Table Bussers |

**Guardrail:** no cost figure may sit beside a cleaning-performance claim, a percentage, or the
word "safe" (Part 3 adjacency). Build the cost block as a *pricing* table.

**4.2 Comparison intent — ✅ via cost, format and labour minutes only.** Not efficacy. The
third-party restaurant-operations figures are context about the reader's business, cited with
source + date; they are never converted into a Wipex product claim.

**4.3 Cost-per-table as the central unit — ✅.** Unlike "cost per wipe" (already used by 16 posts),
"per table" is a pricing unit, not a performance claim. Allowed.

**4.4 🟡 CTA "Reduce Table Turnover Time" — MEDIUM finding, needs Dean.** An outcome claim about
operational time, untested for these SKUs. Keep it as an objective, never a measured result:

- ✅ "Reduce Table Turnover Time" (imperative objective, no claim of measurement)
- ✅ "Designed around faster table resets"
- ❌ "Cuts table reset time by 30%"
- ❌ "Reduce table turnover time — proven"
